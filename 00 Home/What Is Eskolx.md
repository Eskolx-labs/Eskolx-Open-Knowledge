# What Is Eskolx

Eskolx is a small research lab working toward **automated data analysis** — by rebuilding the tools analysts and statisticians normally use as black boxes, and teaching everything we learn.

## What We Do

- Rebuild statistical and numerical tools from first principles (mathematics → algorithm → implementation → testing → validation)
- Preserve the whole learning process, not just final answers
- Publish what we learn as an open learning library

## What Eskolx Is

- A public learning library for statistics, statistical computing, programming, and data analysis automation
- A place where questions drive research: `Question → Research → Mathematics → Algorithm → Implementation → Testing → Reference Comparison → Improvement → Explanation → Teaching`

## What Eskolx Is Not

- Not a content farm — public notes are curated and reviewed, never raw internal dumps
- Not a big company — a small, focused lab

## Where The Code Lives

Knowledge lives here in this vault. Software lives in the Eskolx GitHub organization's code repositories. Project pages link the two together.
