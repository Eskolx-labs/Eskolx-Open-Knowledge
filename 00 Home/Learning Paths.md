# Learning Paths

Curated sequences through the vault. Start at the beginning of a path; each step links to the next.

## Statistical Computing

1. [[Probability]] foundations
2. Random variables and [[Expectation]]
3. [[Distributions]] — build each one from scratch
4. [[Monte Carlo]] methods
5. [[Numerical Methods]]

## Numerical Methods

1. Floating point and [[Numerical Stability]]
2. Linear algebra fundamentals
3. Integration and quadrature
4. Optimization

## Data Analysis Automation

1. Statistical computing foundations (above)
2. Implement a data analysis pipeline from scratch
3. Automate the pipeline
