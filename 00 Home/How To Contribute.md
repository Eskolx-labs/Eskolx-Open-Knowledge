# How To Contribute

Anyone can contribute. Start here.

## Contributor Ladder

`Founder → Intern → Contributor → Trusted Contributor → Core Collaborator`

- **Intern / Contributor**: work in Eskolx-Open only (this vault).
- **Core Collaborator**: also gets access to Eskolx-Core (the private vault).

## Ways To Contribute

- Answer a research question ([[First Contribution]])
- Write or improve a concept note in `02 Knowledge/`
- Review open PRs on the GitHub repository
- Point out errors in published notes — open an issue or PR

## The Public Knowledge Pipeline

`private thought → research → validation → public rewrite → review → public knowledge`

Everything here must stand on its own for someone who wasn't in the room. Never copy-paste internal notes.

## The Quality Gate

Before a knowledge note is published, it must be:

- Correct?
- Understandable?
- Referenced?
- Self-contained?
- Free of private information and secrets?
- Learnable by another student?

If any answer is no, keep it in draft/review.

## Git Workflow

Branch-per-edit + PR. See [[Start Here]] for the exact steps. Never commit to `main`.
