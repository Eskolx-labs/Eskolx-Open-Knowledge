# How To Learn With Eskolx

Eskolx teaches by rebuilding black boxes. Here is how to use the vault as a learning path.

## The Learning Method

`Question → Research → Mathematics → Algorithm → Naive implementation → Testing → Reference comparison → Numerical/performance improvement → Explanation → Teaching`

## Follow A Learning Path

[[Learning Paths]] — curated sequences through Projects, Knowledge, Tutorials, Research, and Resources.

## Find Material

- **Knowledge** (`02 Knowledge/`) — settled, atomic concept notes
- **Research** (`07 Research/`) — exploratory, in-progress investigation
- **Tutorials** (`03 Learning/`) — step-by-step teaching
- **Resources** (`05 Resources/`) — curated external material with reasons to use it

## Learn By Doing

1. Pick a question that interests you
2. Research it in this vault
3. Rebuild the tool yourself — implement, test, compare against a reference like SciPy
4. Write up your explanation as a note
5. Teach it — teaching is part of the loop

## Questions Drive Research

Prefer questions over subjects: *"Why does the Student t-distribution have heavier tails?"* is a research question; *"Student t notes"* is not.
