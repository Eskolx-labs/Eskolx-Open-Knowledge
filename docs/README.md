# Docs

The guides for working in this vault. Start at the top and follow the links. Each guide points to the next one, so you can read straight through or jump in where you need to.

## The path

1. [Getting started](getting-started.md): open the vault, trust the author, take your first look around.
2. [Keybindings](keybindings.md): the shortcuts that run this vault.
3. [Writing notes](writing-notes.md): templates, properties, tags, and linking.
4. [tldraw](tldraw.md): diagrams, the visual language of the library.
5. [Contributing](contributing.md): fork, write, open a pull request.

## The rest

- [tldraw](tldraw.md): create, save, embed, and keep diagrams portable.
- [Contributing](contributing.md): the full contribution workflow and review standards.

## How to read this

If you just cloned the vault, start with [Getting started](getting-started.md). It takes about five minutes and gets you to a working vault. From there, [Keybindings](keybindings.md) teaches you the shortcuts, [Writing notes](writing-notes.md) teaches you how notes are made, and [tldraw](tldraw.md) teaches you the diagrams. When you are ready to give back, [Contributing](contributing.md) walks you through your first pull request.

The docs grow as the vault grows. If a guide is missing or wrong, fix it. That is a contribution too.
