# Keybindings

The shortcuts that run this vault. `Mod` means `Ctrl` on Windows and Linux, `Cmd` on macOS.

## The essentials

| Shortcut | Action |
|---|---|
| `Mod+Shift+A` | **Eskolx Command Center**: create a new note from a template |
| `Mod+Shift+H` | Open Home, the dashboard |
| `Mod+T` | Open the template picker |
| `Mod+O` | Quick switcher: jump to any note by name |
| `Mod+H` | Toggle highlight on the selected text |

## Git

| Shortcut | Action |
|---|---|
| `Mod+Shift+P` | Git: pull |
| `Mod+Shift+S` | Git: push |
| `Mod+Shift+U` | Git: push (alternate) |

Obsidian Git auto-commits your changes locally every few seconds. Pull and push are manual. Pull before you start a session, push when you are done.

## Creating notes

The fastest way to create a note is `Mod+Shift+A`, then pick a type:

- **New Concept**: a settled idea, lands in `02 Knowledge/`
- **New Research**: an open question, lands in `04 Research/`
- **New Resource**: a book, paper, course, or tool, lands in `03 Resources/`
- **New Project**: a project page, lands in `01 Projects/`

Each choice asks for a name, then creates the note from the template and moves it to the right folder automatically.

## Inside a note

- `Mod+E` toggles edit and reading view.
- `Mod+Shift+F` searches the whole vault.
- `[[` starts a link to another note. Type the name, pick from the list.
- `![[` embeds a file (an image, a tldraw scene) inline.

## tldraw

Inside a tldraw canvas, the shortcuts are different. See [tldraw](tldraw.md) for the drawing tools.

## Change a shortcut

Settings → Hotkeys. Search for the command, click the key, press the new one. Your changes are stored in `.obsidian/hotkeys.json`, which is committed, so they apply to everyone. Change a shortcut only if it is a real improvement.
