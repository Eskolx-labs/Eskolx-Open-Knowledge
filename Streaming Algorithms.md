**Streaming algorithms** process data sequentially as it arrives, rather than storing the entire dataset in memory. They are designed for situations where data volumes are too large to fit into memory or where real-time processing is required.

Characteristics:

- Single-pass processing
- Low memory usage
- Fast updates
- Suitable for real-time analytics

Examples include:

- Online mean and variance computation
- Count-Min Sketch
- Bloom Filters
- Reservoir Sampling

Streaming techniques are essential in big data systems, network monitoring, and distributed computing environments.
